# Voicemod-ish 🎙️

A lightweight, customizable voice modulation and sound manipulation tool. Inspired by popular voice-changing software, **Voicemod-ish** is designed to let you tweak, alter, and play with your microphone output on the fly. 

## 🚀 Features
* **Real-time Voice Modulation:** Apply effects to your microphone input with minimal latency.
* **Custom Audio Profiles:** Save and load your favorite voice effect combinations.
* **Lightweight & Fast:** Designed to be resource-efficient so it won't impact your gaming or streaming performance.
* **Standalone Executable:** Easy to run without complex setups.

## 🛠️ Installation & Usage
1. **Download the executable:** Grab the latest `.exe` release from the repository.
2. **Run the App:** Launch `voicemod-ish.exe`. 
3. **Select Audio Devices:** Choose your input (microphone) and output (virtual audio cable or speakers).
4. **Apply Effects:** Pick your desired voice effect and start talking!

*(Note: Depending on the specific effects, you may need to install a Virtual Audio Cable to route the modified voice to other applications like Discord or OBS).*
